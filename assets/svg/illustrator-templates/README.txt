ILLUSTRATOR MASK TEMPLATES

Open the files ending in -mask-template.svg, not the production -fill.svg files.

The black-and-white frame is a browser-rendered reference image. It will not be
misinterpreted as live Braille text by Illustrator. The translucent magenta
shape in the EDIT_MASK group is the only vector artwork you need to change.

1. Keep the artboard size unchanged.
2. Reshape the magenta path so it sits just inside the white dotted frame.
3. Keep it as one closed shape. Do not add holes, strokes, or gradients.
4. Do not move, scale, crop, or edit the reference image.
5. Save the edited template as SVG and return it. The website applies the
   black-to-transparent gradient separately.
