Project overview

    
In this project, we will turn a single 2D image into an animated 3D character and place it inside a web application that allows viewers to interact with the character and experience it in augmented reality (AR).

    


Photoshop Collage → Meshy / Krea AI 3D → Mixamo / Meshy Rigging → GLB + USDZ → Website

    

    
We will use our Fuser accounts to access Meshy, generate and rig our characters, and export them for the web. You can also use Meshy or Krea independently, although free plans may limit textures, exports, and rigging features.

  


  

    
Create a clear source image

    
Begin with a clean, front-facing, full-body character image. The 3D generator has to invent everything it cannot see, so a clear silhouette will produce a more usable model.

    
    
      
  1. Create a character or collage in Photoshop and remove the background.
    2. 
      
  2. Position the character in an A-pose or T-pose, with arms away from the torso and legs separated.
    3. 
      
  3. Make sure the hands and feet are visible and nothing is cropped.
    4. 
      
  4. Export the image as a PNG with a transparent or plain background.
    5. 
    

  


  

    
Generate a 3D model

    
    
      
  1. Open Meshy through your Fuser account, or use Meshy / Krea independently.
    2. 
      
  2. Select Image to 3D and upload your PNG.
    3. 
      
  3. Choose an A-pose or T-pose if pose controls are available.
    4. 
      
  4. Generate your model and inspect it from all sides.
    5. 
      
  5. Generate textures if they are not already included.
    6. 
    

    
Remember that the AI invents the back and sides of your character. Check for missing limbs, distorted geometry, and disconnected parts before continuing.

  


  

    
Rig and animate

    
Rigging creates a digital skeleton that allows the character to move.

    
Option A: Meshy

    
    
      
  1. Use Meshy's built-in rigging tool.
    2. 
      
  2. Choose an animation from the available library.
    3. 
      
  3. Preview the animated character.
    4. 
      
  4. Export the animated model as GLB.
    5. 
    

    
Option B: Mixamo

    
    
      
  1. Export your character from the 3D generator in a compatible format, such as FBX or OBJ.
    2. 
      
  2. Upload it to Mixamo.
    3. 
      
  3. Position the rigging markers on the character.
    4. 
      
  4. Choose an animation and adjust its settings.
    5. 
      
  5. Download the animated character as FBX.
    6. 
      
  6. Convert the animated FBX to GLB using Blender or another compatible tool.
    7. 
    

  


  

    
Prepare the files for AR

    
Our website will use two versions of the same character:

    

      

        

          
GLB:
for displaying the animated character in the browser and supported Android AR experiences.

          
USDZ:
for Apple's AR Quick Look on iPhone and iPad.

        

      

    

    
Export the GLB from Meshy and convert it to USDZ using a compatible conversion tool. Make sure textures, materials, and animations are preserved where supported.

    

      

        

          
USDZ converter:
meshy-to-usdz-by-code-as-nature-f26.fuser.app

        

      

    

    
You can test your GLB in the model-viewer editor. Confirm that the textures appear correctly and the animation plays.

    
Test the USDZ by opening it on your iPhone or iPad. Check that the character appears correctly in AR. Animation support may differ between the browser preview and Apple's AR Quick Look.

  


  

    
Build the website

    
Create the following folder inside your portfolio website:

├── index.html

We will use Google's <model-viewer> web component to display our 3D character directly in the browser.

    
It allows visitors to rotate, zoom, and inspect the model, play its embedded animation, and launch AR on supported devices. The HTML defines the viewer and its attributes, CSS controls its appearance, and JavaScript allows us to add custom interactions.

<model-viewer> attributes

    

      

        
Important <model-viewer> attributes

        

          
src="character.glb"
Loads the 3D model for web and Android.

          
ios-src="character.usdz"
Loads the Apple AR version.

          
alt="..."
Provides an accessible description.

          
camera-controls
Enables rotation and zoom.

          
autoplay
Automatically plays the model's animation.

          
loop
Repeats the animation (note: looping is already the default in model-viewer).

          
shadow-intensity="1"
Controls shadow strength.

          
exposure="1"
Controls the model's brightness.

          
ar
Enables augmented reality.

          
ar-placement="floor"
Places the model on a horizontal surface.

          
ar-scale="auto"
Allows the model to be resized in supported AR modes.

          
ar-modes="webxr scene-viewer quick-look"
Specifies supported AR methods and their priority.

          
slot="ar-button"
Assigns a custom button to launch AR.

        

      

      

        
Additional attributes to experiment with

        

          
auto-rotate
Automatically rotates the model.

          
rotation-per-second="30deg"
Controls automatic rotation speed.

          
camera-orbit="0deg 75deg 3m"
Sets the initial camera angle and distance.

          
field-of-view="30deg"
Controls camera perspective.

          
camera-target="0m 1m 0m"
Sets the point the camera looks at.

          
environment-image="neutral"
Changes environmental lighting and reflections.

          
shadow-softness="1"
Controls shadow softness.

          
scale="1 1 1"
Sets the model's scale.

          
orientation="0deg 0deg 0deg"
Sets the model's orientation.

          
animation-name="..."
Selects a specific embedded animation.

          
interaction-prompt="none"
Hides the default interaction hint.
