Anatomy of a p5 sketch

Almost every p5 sketch, however complex it gets, is built from the same two functions.

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(220);
  ellipse(mouseX, mouseY, 50, 50);
}
SETUP

Runs once, right when the sketch starts. This is where anything that only needs to happen a single time goes — almost always includes createCanvas(width, height), which creates the drawing area itself.

DRAW

Runs over and over, about 60 times a second, for as long as the sketch is open. background(220) repaints the canvas each frame — this is what erases the previous frame before the new one draws. mouseX / mouseY are built-in variables that always hold the mouse's current position, which is why the circle follows it. Move background(220) into setup() instead, and it only paints once, before the loop even starts — nothing inside draw() ever clears the canvas again, so every new circle stacks on top of the last instead of replacing it, leaving a trail across the screen as the mouse moves.

Loading the library

p5.js isn't built into the browser — it has to be loaded first, before your own sketch file.

<script src="https://cdn.jsdelivr.net/npm/p5@1.11.8/lib/p5.min.js"></script>
<script src="sketch.js"></script>

The first line loads the p5.js library itself from a CDN — a server that hosts the file for you, no download needed. The second loads your own sketch file, which can now use setup(), draw(), and everything else on this page, because the library just defined them. Order matters: the library has to load first.

Try p5.js's own setting up your environment tutorial.

Shapes & color

The functions you'll use in almost every sketch.

x and y are pixel positions on the canvas, measured from its top-left corner: x counts rightward from 0 at the left edge, y counts downward from 0 at the top edge — the opposite of a typical math graph, where y increases upward. So rect(10, 10, 50, 50) sits near the top-left of the canvas, not the bottom.

Canvas & shapes

createCanvas(w, h)
— creates the drawing area. Call once, in setup().
background(color)
— fills the whole canvas with a color. Usually the first line in draw().
rect(x, y, w, h)
— a rectangle. x, y is its top-left corner by default; w, h its width and height.
ellipse(x, y, w, h)
— an ellipse; a circle when w equals h. x, y is its center here, not a corner.
line(x1, y1, x2, y2)
— a straight line between two points: x1, y1 where it starts, x2, y2 where it ends.
triangle(x1, y1, x2, y2, x3, y3)
— a triangle from three x, y points, one per corner.

Color

fill(color)
— sets the fill color for shapes drawn after it.
stroke(color)
— sets the outline color.
noFill() / noStroke()
— turns off the fill or outline entirely.
colorMode(HSB)
— switches how color values are interpreted. Default is RGB.

Input & animation

Reading what the user is doing, and making things move.

Input

mouseX / mouseY
— variables that always hold the mouse's current position.
mousePressed()
— a function p5 calls automatically, once, the moment a mouse button is pressed.
keyPressed()
— same idea, for the keyboard.
key
— a variable holding the most recently pressed key.

Motion & animation

frameCount
— a variable that counts up by 1 every frame since the sketch started.
random(min, max)
— a random number in that range.
map(value, s1, e1, s2, e2)
— rescales a number from one range into another. map(mouseX, 0, width, 0, 255) takes mouseX, which ranges from 0 to width as it crosses the canvas, and converts it to a matching position between 0 and 255 — handy for turning mouse position directly into a color or size value.
lerp(start, stop, amt)
— a value partway between start and stop, where amt is 0 to 1: lerp(0, 100, 0.5) returns 50, halfway between. For smooth movement, run it every frame with the current position as start: x = lerp(x, targetX, 0.1); nudges x 10% closer to targetX each frame, easing toward it instead of jumping straight there.

Beyond p5.js

Two libraries worth knowing exist, once a project outgrows what's on this page. Not covered in depth here — just pointers.

ml5.js — machine learning

Friendly, pre-trained machine-learning models — pose detection, hand tracking, image classification — built to drop straight into a p5 sketch. ml5js.org · Getting Started tutorial (builds a hand-tracking sketch from zero).

three.js — real 3D

3D graphics using WebGL, where p5 is primarily 2D. A different mental model — scene, camera, renderer, and mesh, instead of setup()/draw(). threejs.org · Creating a Scene tutorial (builds a first rotating cube).
