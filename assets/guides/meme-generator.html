What is an API?

    
An API (Application Programming Interface) lets your website request data or functionality from another website or database.

    
Instead of storing all the information ourselves, our website can request it from another source:


    
your website → API → data → your website


    
Different sources are accessed in different ways:

    

      

        

          
API:
Use fetch() to request data, then usually .json() to convert the response into data JavaScript can use.
Example: fetch("https://api.adviceslip.com/advice").then(response => response.json()).then(data => { memeText.textContent = data.slip.advice; });

          
Direct Image:
Give the image URL directly to the src of an image.
Example: memeImage.src = "https://cataas.com/cat";

          
Generated Image:
Build an image URL using your own text or variables.
Example: memeImage.src = "https://robohash.org/hello";

          
API → Image:
Request data containing an image URL, then give that URL to the image on your page.
Example: fetch("https://yesno.wtf/api").then(response => response.json()).then(data => { memeImage.src = data.image; });

          
Dataset:
Load a JSON, CSV, or text file and use values from it on your page.
Example: fetch("data.json").then(response => response.json()).then(data => { memeText.textContent = data[0].text; });

          
Directory:
Use the website to find an API or dataset. The directory itself usually isn't accessed by your code.
Example: Find an API → find its endpoint → use that endpoint in your JavaScript.

          CONVERT JSON
          
The API responds with JSON. This converts it into data JavaScript can use.

        


        

          RECEIVE DATA
          
data now contains everything the API returned.

        


        

          USE THE DATA
          
Selects the advice from the returned data and puts it inside our <p> element.

Build the meme generator

    
Copy the index.html from last week's folder into this week's folder, and replace the title and body content with this week's.

    
Add this to the <body>:


    

      

        


<div class="meme">
  <img class="meme-image" id="meme-image" src="" alt="Random meme">
  <p class="meme-text" id="meme-text">Click the button.</p>
</div>
<br>
<button id="generate-button">[ Generate Meme ]</button>

<script src="script.js"></script>

        

      

    


    
Create a script.js in this week's folder and add this:


    

      

        


const button = document.getElementById("generate-button");
const memeText = document.getElementById("meme-text");
const memeImage = document.getElementById("meme-image");

button.addEventListener("click", generateMeme);

function generateMeme() {

  // Get text
  fetch("https://corporatebs-generator.sameerkumar.website/?" + Date.now())
    .then(response => response.json())
    .then(data => {
      memeText.textContent = data.phrase;
    });

  // Get image
  fetch("https://yesno.wtf/api?" + Date.now())
    .then(response => response.json())
    .then(data => {
      memeImage.src = data.image;
    });

}

Where to find APIs

    
More sources you can use the same way: request data or an image URL, then put it into memeText or memeImage.


    

      
Meme Generators

    
    
      
  • 
        
    Memegen.link — Generated Image
    Open-source meme generator with hundreds of templates. No account required.
    
        
    The template and text are part of the image URL:
    
        
    
          
    
            
    

    memeImage.src =
  "https://api.memegen.link/images/drake/no/yes.png";
    
            
    
          
    
        
    
        
    Changing no and yes changes the text:
    
        
    
          
    
            
    

    memeImage.src =
  "https://api.memegen.link/images/drake/coding/debugging.png";
    
            
    
          
    
        
    
        
    memegen.link

    Imgflip — API
    Large collection of familiar meme templates.
    
        
    Request the available templates:
    
        
    
          
    
            
    

    fetch("https://api.imgflip.com/get_memes")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  });

    Creating finished memes through the API requires authentication.
    
        
    imgflip.com/api

GIFs

    
    
      
  • 
        
    GIPHY — API → Image
    Probably the most useful addition. Supports search, trending and random GIFs.
    
        
    For example, a random GIF:
    
        
    
          
    
            
    

    const memeImage = document.getElementById("meme-image");

fetch(
  "https://api.giphy.com/v1/gifs/random?api_key=YOUR_API_KEY"
)
  .then(response => response.json())
  .then(data => {
    memeImage.src = data.data.images.original.url;
  });
    
            
    
          
    
        
    
        
    Or search for something:
    
        
    
          
    
            
    

    const memeImage = document.getElementById("meme-image");

fetch(
  "https://api.giphy.com/v1/gifs/search?api_key=YOUR_API_KEY&q=ghost&limit=1"
)
  .then(response => response.json())
  .then(data => {
    memeImage.src = data.data[0].images.original.url;
  });
    
            
    
          
    
        
    
        
    Requires a free account/API key. New beta keys are currently limited to 100 API calls per hour. See the quick start guide.
    
        
    developers.giphy.com/docs

    GifCities — Archive
    An Internet Archive project containing animated GIFs recovered from old GeoCities websites.
    
        
    Rather than contemporary reaction GIFs, you get things like under construction signs, spinning skulls, flames, sparkles, dancing babies, email icons, animated text, and other 90s web graphics.
    
        
    Picks a random search term, searches GifCities for it, then picks a random result and builds its archived GIF URL:
    
        
    
          
    
            
    

    const memeImage = document.getElementById("meme-image");

const words = [
  "cat",
  "star",
  "fire",
  "love",
  "home",
  "web",
  "cool",
  "music",
  "computer",
  "welcome",
  "email",
  "angel",
  "skull",
  "rainbow"
];

const word = words[Math.floor(Math.random() * words.length)];

fetch("https://gifcities.archive.org/api/v1/gifsearch?q=" + word)
  .then(response => response.json())
  .then(data => {
    const result = data[Math.floor(Math.random() * data.length)];

    const gifURL =
      "https://web.archive.org/web/" +
      result.gif.replace("/", "im_/");

    memeImage.src = gifURL;
  });
    
            
    
          
    
        
    
        
    gifcities.org

    Homosaurus — API / Linked Data
    A structured vocabulary of LGBTQ+ terminology and relationships between concepts. Terms can include broader, narrower and related concepts. The data is available in formats including JSON-LD.
    
        
    For example, request the Homosaurus concept LGBTQ Arts as JSON-LD:
    
        
    
          
    
            
    

    const term = document.getElementById("term");

fetch("https://api.homosaurus.org/v2/LGBTQArts.jsonld")
  .then(response => response.json())
  .then(data => {
    term.textContent = data["http://www.w3.org/2004/02/skos/core#prefLabel"];
  });
    
            
    
          
    
        
    
        
    Homosaurus is particularly interesting because the data describes relationships between concepts, rather than just returning a random piece of text. For example, LGBTQ Arts is connected to concepts including artists, drag, LGBTQ films, literature, theatre and art censorship.
    
        
    You can also download the larger vocabulary in machine-readable formats including JSON-LD, CSV, XML and TTL.
    
        
    homosaurus.org

    Pronouns.page — API → Text / Data
    An explicitly queer API containing pronouns and related linguistic data. Most public endpoints do not require authentication.
    
        
    For example, get all available pronoun sets and put the first one into your page:
    
        
    
          
    
            
    

    <p id="pronoun"></p>
    
            
    
          
    
        
    
        
    
          
    
            
    

    const pronoun = document.getElementById("pronoun");

fetch("https://en.pronouns.page/api/public/v3/pronouns")
  .then(response => response.json())
  .then(data => {
    pronoun.textContent = data[0].name;
  });
    
            
    
          
    
        
    
        
    The API returns information including the pronoun name, subject and object forms, possessive forms, reflexive form, descriptions and example sentences.
    
        
    You could display an example sentence instead:
    
        
    
          
    
            
    

    const text = document.getElementById("text");

fetch("https://en.pronouns.page/api/public/v3/pronouns")
  .then(response => response.json())
