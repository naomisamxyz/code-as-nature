Weekly portfolio setup

One folder, one home page, one folder per week. Set it up once, then add a week folder each time you have new work.

Install your tools

Two programs, both free, one-time installs.

1. VS Code

The text editor for every HTML, CSS, and JS file. Download from code.visualstudio.com and run the installer.

2. Live Server (optional)

A VS Code extension that opens your page in a browser tab and reloads it on every save. In VS Code, open Extensions (the four-squares icon), search Live Server, install the one by Ritwick Dey.

Without it, double-clicking index.html still opens the page, but you'd have to reload the browser manually after every change.

How the template is organized

One folder, same shape every week.

At the root

index.html:
the home page. Lists every week and links into each week's folder.
style.css:
shared styles for the whole portfolio.
script.js:
shared JS for the whole portfolio.
week1/ through week14/:
one folder per week, each holding that week's own index.html.
images/:
image files used across the site.
fonts/:
font files used across the site.

Adding a new week

All 14 week folders already exist. Only the index.html file inside the one you're working on needs to be changed, and the preview file removed or adapted.

  1. Open the folder for the week you're working on, week3 for example.
  2. Open its index.html.
  3. Replace the content with that week's sketch and write-up.
  4. If needed, add/change/remove preview.html, script.js, style.css, or other assets your sketch uses (images, sound, data) in the same folder.

Properly compress images for web, keep each file around 100–300KB. Host video elsewhere (YouTube, Vimeo) instead of committing it directly. Git keeps every version you've ever committed, so unoptimized files bloat the repository fast. The limit for GitHub Pages is around 1GB.

Previewing it live

This is where Live Server, installed above, actually gets used.

  1. In VS Code, open the whole portfolio folder (File → Open Folder…).
  2. Right-click index.html in the file list and choose Open with Live Server.
  3. A browser tab opens automatically, showing the real page. Every time you save a change to any file, that tab refreshes on its own, no manual reloading needed.
