Anatomy of a function

    
A function is a named, reusable block of code, one of the most common shapes you'll write in JavaScript.


    


      

        

          
          
          
        

        


function greet(name) {
  return "Greetings, " + name;
}

        

      


      


        

          HEADER
          
function is the keyword that starts a function definition. greet is the name you're giving it, what you'll use to run it later. (name) is a parameter: a placeholder for a value the function expects each time it runs. The { opens the function's body.

        


        

          BODY
          
The code that actually runs when the function is called. return sends a value back out of the function, here a greeting built by joining two strings together with +.

        


        

          CLOSING BRACE
          
} closes the function body, matching the { from the header line.

        


      


      

        

        

        

        


        

        

        

        


        

        

        

        

      


    

  


  

  

    
Variables & values

    
A variable is a named box for a value. What kind of value it holds is one of a small handful of basic types.


    

      

        
Declaring a variable

        

          
let score = 10;:
a variable that can be reassigned later, e.g. score = 20;.

          
const artistname = "serenityspellcaster";:
a variable that can't be reassigned once set. Use this by default; switch to let only when you actually need to change it.

        

      


      

        
Basic types

        

          
"hello":
a string. Text, always in quotes.

          
10, 3.14:
a number. No quotes.

          
true, false:
a boolean. Exactly one of two values.

          
[1, 2, 3]:
an array. An ordered list of values, indexed from 0: the first item is arr[0], not arr[1].

          
{ key: "value" }:
an object. Groups related values under names you choose, e.g. const specimen = { artistname: "serenityspellcaster", age: 25 }; has an artistname and an age. Access one with a dot on the variable holding it: specimen.artistname returns "serenityspellcaster". Compare that to an array, where you'd access by numbered position instead, like arr[0].

        

      

    

  


  

  

    
Reacting to a click

    
A small working example: variables, finding elements on the page, and reacting to an event, all in one place. Given this HTML:


    

      

        


<button id="btn">pulseButton</button>
<p id="txt">Signal: dormant</p>

        

      

    


    
…this JS finds both elements, then listens for a click:


    


      

        

          
          
        

        


const button = document.querySelector("#btn");
const text = document.querySelector("#txt");

button.addEventListener("click", function () {
  text.textContent = "Signal: alive";
  document.body.style.background = "yellow";
});

        

      


      


        

          SELECT ELEMENTS
          
document.querySelector("#id") finds one element already on the page and hands it back. Both results are stored in variables (button and text) so they can be reused below without searching the page again.

        


        

          EVENT LISTENER
          
addEventListener("click", …) tells the browser to run a function every time this element is clicked. Everything inside the function's { } runs on each click, here changing the paragraph's text and the page's background color.

        


      


      

        

        

        

        


        

        

        

        

      


    

  


  

  

    
Control flow & functions

    
The handful of building blocks that show up in almost every script.


    

      

        
Functions

        

          
function name() { }:
a named, reusable block of code.

          
return:
sends a value back out of a function, and immediately stops it.

        

      


      

        
Control flow

        

          
if / else:
run one block of code only when a condition is true, otherwise run the other.

          
for (let i = 0; i < 5; i++):
repeat a block a set number of times.

          
while:
repeat a block for as long as a condition stays true.

          
===:
strict equality: checks value and type. Use this over == almost always.

        

      

    


    
Control flow in practice

    
Put together, these building blocks look like this: a loop that checks every item in a list, reacting differently depending on what it finds:


    

      

        


const materials = ["glass", "metal", "spikes", "thorns"];

for (let i = 0; i < materials.length; i++) {
  if (materials[i] === "spikes") {
    console.log("Found it!");
  } else {
    console.log("Not yet");
  }
}

        

      

    


    
materials is an array (an ordered list of values, from the types reference above) holding four strings. materials.length is the number of items it holds, so here it's 4; add or remove items and .length updates automatically.


    
The for loop's parentheses have three parts, separated by semicolons: let i = 0 runs once, before the loop starts. i < materials.length is checked before every pass. As long as it's true, the loop keeps going. i++ runs after each pass, adding 1 to i. Together, these repeat the block once for every item in materials, with i counting 0, 1, 2, and so on.


    
Inside that loop, if (materials[i] === "spikes") checks a condition on each pass. === is strict equality: it checks both value and type, the safer choice over ==, which allows mismatched types to sneak through as equal. If the condition is true, the first { } block runs; if it's false, the else block runs instead, never both, and never neither.


    
Once i reaches materials.length, the loop's condition becomes false, the loop stops, and execution moves on to whatever code comes after the closing }.

  


  

  

    
The DOM & events

    
How JavaScript finds, changes, and reacts to what's on the page.


    
"DOM" stands for Document Object Model: it's the browser's live copy of your HTML, built in memory as a tree of elements the moment the page loads. It's not the HTML file itself; it's what the browser is actually showing you right now. JavaScript reads and changes this live copy (not the file on disk), so updates show up on screen instantly, without ever touching your HTML.


    

      

        
The DOM

        

          
document.querySelector("…"):
finds the first element on the page matching that CSS selector.

          
.textContent:
reads or changes an element's text.

          
.style:
reads or changes an element's inline CSS, e.g. el.style.color = "red".

          
.classList.add("…"):
adds a class, usually to trigger a CSS change. .remove("…") takes it back off.

        

      


      

        
Events

        

          
addEventListener("click", fn):
runs fn every time the element is clicked.

          
"input":
fires as someone types into a field.

          
"keydown":
fires when a key is pressed.
