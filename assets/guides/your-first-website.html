⭐︎ Open Portal ⭐︎

The smallest possible website you can make.

Make a project folder Write the HTML Write the CSS Open it in your browser Add an image

Make a project folder

Every website starts as a folder of files sitting on your computer, before it's anything else.

  1. Anywhere on your computer (your Desktop is fine), make a new folder. Call it something like open-portal.
  2. Next, add two files inside it.

Write the HTML

Inside that folder, make a new file named exactly index.html. A browser opens this file automatically when given the folder. Paste this in:

<!DOCTYPE html>
<html>
<body>
  <h1>⭐︎ Open Portal ⭐︎</h1>
</body>
</html>
PAGE SETUP

The standard opening every HTML page starts with.
<!DOCTYPE html> tells the browser this is a modern HTML page.
<html> wraps everything on it.
The HTML essentials cover these lines in detail.

BODY STARTS

<body> opens the part that actually shows up on screen. Everything visible on the page goes between here and </body>.

CONTENT

The one thing on this page: a heading, using the biggest heading tag, <h1>. Change the words between the tags and that's what shows up.

CLOSING

</body> closes the visible part of the page.
</html> closes the whole document.
Every opening tag needs a matching closing one. This is where these two get theirs.

Write the CSS

Right next to index.html, in the same folder, make a second file named exactly style.css. Paste this in:

body {
  background: black;
  font-family: sans-serif;
}

h1 {
  color: silver;
}
BODY RULE

body targets the whole page: the outermost element every other tag sits inside.
background sets the page's color.
font-family sets the typeface for all its text, including headings, unless something more specific overrides it.

H1 RULE

h1 targets just the heading you wrote.
color here only affects text inside h1 elements. It doesn't touch the rest of the page.
Try changing either color once it's connected below. The full syntax behind rules like these is in the CSS essentials.

That file does nothing yet: nothing points to it. Go back to index.html and add a <head> section between <html> and <body>, with a <link> tag inside it:

<html>
<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
CONNECTS TO CSS

This goes between the <html> you already have and <body>.
<head> starts a section for information about the page rather than content you see.
<link> pulls in the stylesheet you just wrote, so its rules apply to this page. Without it, the CSS file would just sit there doing nothing.

Save both files, then reload the page in the next section to see the color change.

Open it in your browser

To view the page:

  1. Find index.html in your folder and double-click it. It should open in your default browser and show “⭐︎ Open Portal ⭐︎” in whatever color you chose.
  2. If it opens as plain text instead of a webpage, right-click the file, choose Open With, and pick a browser (Chrome, Safari, or Firefox) instead.
  3. Every time you save a change to either file, switch back to the browser tab and refresh it to see the update. The browser only reads the files when you tell it to.

Add an image

One more line to try, now that the page works. Pick any image on your computer (a photo, a screenshot, a drawing) and drag it into the same folder as index.html.

<h1>⭐︎ Open Portal ⭐︎</h1>
<br>
<img src="assets/images/header-glow.png" alt="a diamond shaped opening of light">

Add these two lines right under your <h1>, still inside <body>.
<br> is a line break. It just pushes whatever comes after it onto a new line, so the image doesn't sit jammed against the heading.
src is the image's file name. Change "assets/images/header-glow.png" to match whatever you dragged in, exactly, including the file extension.
alt is a short written description of the image, used by screen readers and shown if the image ever fails to load.
Save, then reload the page to see it appear below the heading. The full picture on images, including sizing and when to use them versus embedding, is in the HTML essentials.
