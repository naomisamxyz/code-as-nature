Make a project folder

    
Every website starts as a folder of files sitting on your computer.

    
This is what the folder is going to look like:

    
OpenPortal/
├── index.html
├── style.css
└── portal.jpg

    
index.html contains the page’s words, structure, and image.

    
style.css controls the page’s colors, type, and spacing.

    
portal.jpg is the image displayed on the page. Your image can have a different name and file extension.

    

    
    
      
  1. Create a new folder.
    2. 
      
  2. Name the folder OpenPortal.
    3. 
      
  3. Open the folder. All the files for this website will go inside it.
    4. 
    

    
For now, the folder is empty. First, we will create the HTML file.

  


  

  

    
Create an HTML file with TextEdit

    
HTML must be saved as plain text. If TextEdit is using rich text, the browser may display your code instead of turning it into a webpage.

    
    
      
  1. Open TextEdit.
    2. 
      
  2. Choose File → New.
    3. 
      
  3. Choose Format → Make Plain Text.
    You can also press Shift + Command + T.
    4. 
      
  4. If TextEdit asks whether you want to convert the document to plain text, confirm.
    5. 
      
  5. Paste this code into the document:
    6. 
    


    


      

        

          
          
        

        


<!DOCTYPE html>
<html>
  <body>
    <h1>⭐︎ Open Portal ⭐︎</h1>
  </body>
</html>

        

      


      


        

          HTML
          
<!DOCTYPE html> tells the browser this is a modern HTML page. The line from <html> to </html> shows that the HTML element wraps the entire document.

        


        

          BODY
          
The nested line from <body> to </body> contains everything visible on the page. The indented <h1> is the heading inside it.

        


      


      

        

        

        

        


        

        

        

        


      


    


    
    
      
  1. Choose File → Save.
    2. 
      
  2. In the save window, enter index.html as the file name. Make sure TextEdit does not add .txt at the end.
    3. 
      
  3. Select the OpenPortal folder as the location.
    4. 
      
  4. If TextEdit asks whether you want to use .txt or .html, choose .html.
    5. 
    

    
Your project folder should now look like this:

    
OpenPortal/
└── index.html

    
The name index.html is important. Web browsers and web servers usually treat a file with this name as the first page of a website.


    

      Make plain text the TextEdit default
      
You can make TextEdit open new documents as plain text automatically:

      
    
        
  1. Open TextEdit → Settings.
    2. 
        
  2. Select New Document.
    3. 
        
  3. Under Format, choose Plain text.
    4. 
      

      
You will still need to give each file the correct extension when saving it, such as .html or .css.

    

  


  

  

    
Open the page in your browser

    
Find index.html inside your project folder and double-click it. It should open in your default browser and display:

    
⭐︎ Open Portal ⭐︎


    

      If it opens in TextEdit instead
      
    
        
  1. Right-click index.html.
    2. 
        
  2. Choose Open With.
    3. 
        
  3. Select Safari, Chrome, or Firefox.
    4. 
      

    


    
Whenever you change your code:

    
    
      
  1. Save the file in TextEdit.
    2. 
      
  2. Return to the browser.
    3. 
      
  3. Refresh the page.
    4. 
    

    
The browser does not automatically know when you have changed the file. Refreshing makes it read the newest version.

If you see <html>, <body>, and the other tags instead of a webpage, return to TextEdit and choose Format → Make Plain Text. Then save the file again and refresh the browser.

      
Also make sure the file is named index.html, not index.html.txt.

Write the CSS

    
HTML gives the page its content and structure. CSS controls what the page looks like.

    
Create a second plain-text file with TextEdit:

    
    
      
  1. Choose File → New.
    2. 
      
  2. Choose Format → Make Plain Text if the document is not already plain text.
    3. 
      
  3. Paste this code:
    4. 
    


    


      

        

          
          
        

        


body {
  background: black;
  font-family: sans-serif;
}

h1 {
  color: silver;
}

        

      


      


        

          BODY RULE
          
body targets the whole page: the outermost element every other tag sits inside.
background sets the page's color.
font-family sets the typeface for all its text, including headings, unless something more specific overrides it.

        


        

          H1 RULE
          
h1 targets just the heading you wrote.
color here only affects text inside h1 elements. It doesn't touch the rest of the page.
Try changing either color once it's connected below. The full syntax behind rules like these is in the CSS essentials.

        


      


      

        

        

        

        


        

        

        

        

      


    


    
    
      
  1. Choose File → Save.
    2. 
      
  2. Name the file style.css.
    3. 
      
  3. Save it inside the same OpenPortal folder as index.html.
    4. 
      
  4. If TextEdit asks which extension to use, choose .css.
    5. 
    

    
Your folder should now look like this:

    
OpenPortal/
├── index.html
└── style.css


    

      Try different body styles
      
You can add more properties between the body rule’s curly brackets:

    
body {
  background: midnightblue;
  color: white;
  font-family: monospace;
  text-align: center;
  padding: 40px;
}

    
Try changing one value at a time.

    
Some background options:

    
background: black;
background: hotpink;
background: linear-gradient(black, darkblue);

    
Some font options:

    
font-family: sans-serif;
font-family: serif;
font-family: monospace;

      
Center everything inside the body with text-align: center;, or add space around the page’s content with padding: 40px;.

    
Try different heading styles

    
You can also experiment with the <h1>:

    
h1 {
  color: silver;
  font-size: 60px;
  letter-spacing: 5px;
  text-transform: uppercase;
}

    
Try color: white;, color: lime;, or color: rgb(255, 100, 200);. Add a glow with text-shadow: 0 0 12px white;, a border with border: 1px solid silver;, and space inside it with padding: 20px;.

    
You can combine several properties in the same rule:

    
h1 {
  color: white;
  font-size: 60px;
  letter-spacing: 5px;
  border: 1px solid silver;
  padding: 20px;
  text-shadow: 0 0 12px white;
}

    
Save style.css and refresh the browser after every change.

    

  


  

  

    
Connect the CSS to the HTML

    
The CSS file does nothing yet because nothing in the HTML points to it.

    
Return to index.html. Add a <head> section between <html> and <body>, with a <link> tag inside it. Your complete HTML should now look like this:


    


      

        

          
          
        

        


<!DOCTYPE html>
<html>
  <head>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>⭐︎ Open Portal ⭐︎</h1>
  </body>
</html>

        

      


      


        

          CONNECTS TO CSS
          
The <head> contains information about the page that does not appear as regular page content.
The <link> tag tells the browser to load your CSS file.
rel="stylesheet" tells the browser what kind of file it is loading.
href="style.css" tells the browser where to find it. Because both files are in the same folder, only the file name is needed.

        


      


      

        

        

        

        

      


    


    
Save index.html, return to the browser, and refresh. The CSS should now change the page’s appearance.

  


  

  

    
Add an image

    
Pick any image on your computer, a photograph, screenshot, drawing, or collage, and drag a copy into the same OpenPortal folder as index.html.

    
For this example, imagine the file is named portal.jpg. Your folder would look like this:

    
OpenPortal/
├── index.html
├── style.css
└── portal.jpg

    
Add an <img> tag underneath the <h1> in index.html:


    

      

        


<body>
  <h1>⭐︎ Open Portal ⭐︎</h1>
  <img src="portal.jpg" alt="A glowing portal">
</body>

        

      

    


    
Replace portal.jpg with the exact name of your own image. The name must match its capitalization, spaces, hyphens, and extension, such as .jpg, .jpeg, .png, .gif, or .webp. Short names with lowercase letters and hyphens, such as my-portal.jpg, are easiest to use.


    

      Understand the image path
      
The src attribute is a path from the HTML file to the image. Because portal.jpg is beside index.html, the path is simply src="portal.jpg".

      
Do not use a complete Mac path such as /Users/your-name/Desktop/OpenPortal/portal.jpg. It will only work on your computer and will break when the website is moved or published. Website paths describe where a file is located inside the project folder.

      
If you later make an images folder and move the image into it:

      
OpenPortal/
├── index.html
├── style.css
└── images/
    └── portal.jpg

      
Then the path must include that folder:

      
<img src="images/portal.jpg" alt="A glowing portal">

      
For this first website, keeping the image beside index.html is completely fine.

    


    
Write useful alternative text

    
The alt attribute describes the image for people using screen readers. It also appears if the image cannot load. For example:

    
alt="A glowing circular portal surrounded by blue light"


    
Resize the image with CSS

    
If the image is too large, add this rule to style.css:

    

      

        

          
          
        

        
img {
  width: 500px;
  max-width: 100%;
  border: 1px solid silver;
  border-radius: 20px;
}

      

      

        

          SIZE
          
width: 500px gives the image a preferred width. max-width: 100% stops it from becoming wider than the browser window on a small screen.

        

        

          OPTIONAL STYLE
          
Add border: 1px solid silver; for a border, or border-radius: 20px; for rounded corners. You can use either line or both. Save both files and refresh the browser.
