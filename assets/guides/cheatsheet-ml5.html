Loading the library

    
ml5.js and p5.js are JavaScript libraries that need to be loaded before your own sketch file inside the index.html file with a <script> tag.


    
index.html
 ├── loads p5.js library
 ├── loads ml5.js library
 └── loads sketch.js

sketch.js
 └── your p5.js + ml5.js code


    
    
      
  • 
        
    Working in the p5.js Web Editor
    
        
    Open index.html from the file list in the p5.js Web Editor. Add the ml5.js script inside the <head>, before its closing </head> tag:
    

        
    
          
    
            
    

    <script src="https://unpkg.com/ml5@1/dist/ml5.min.js"></script>
    
            
    
          
    
        
    

        
    The Web Editor already loads p5.js and your sketch.js file. This additional line makes the ml5 library available to that sketch.
    
      
    • 
      
  • 
        
    Working in your own local website with internet access
    
        
    In your local index.html, load p5.js first, ml5.js second, and your own sketch last:
    

        
    
          
    
            
    

    <script src="https://cdn.jsdelivr.net/npm/p5@1.11.8/lib/p5.min.js"></script>
<script src="https://unpkg.com/ml5@1/dist/ml5.min.js"></script>
<script src="sketch.js"></script>
    
            
    
          
    
        
    

        
    Order matters. Your sketch can use p5.js and ml5.js only after both libraries have loaded.
    
      
    • 
      
  • 
        
    Working in your own local website without internet access
    
        
    While you still have internet access, download p5.min.js and ml5.min.js. Save both files next to index.html and sketch.js.
    

        
    your-project/
├── index.html
├── p5.min.js
├── ml5.min.js
└── sketch.js
    

        
    Then load the local library files instead of the internet addresses:
    

        
    
          
    
            
    

    <script src="p5.min.js"></script>
<script src="ml5.min.js"></script>
<script src="sketch.js"></script>
    
            
    
          
    
        
    

        
    This makes the p5.js and ml5.js library files available offline. Many ml5.js models load additional model data when the sketch starts. Those model files must also be saved locally and connected using that model’s instructions before the complete project can run without internet access.
    
      
    • 
    

  


  

  

    
Loading the model

    
The <script> tag from the previous step loads the ml5.js library and makes its tools available to your JavaScript as ml5. Think of ml5 as a toolbox: loading the library gives you access to the toolbox, but it doesn't load every AI model inside it.

    
When you call a model in sketch.js, for example ml5.faceMesh() or ml5.handPose(), ml5 then downloads the pretrained model and its weights that it needs to run. This is a separate and usually larger download.

    
So there are two steps:

    
index.html → loads ml5.js library → sketch.js calls a model → model weights are downloaded


    
    
      
  • 
        
    Online
    
        
    By default, the model weights are fetched automatically from ml5's servers the moment you call the model function. Nothing extra to set up, but the sketch needs an internet connection the first time it runs so the model can download.
    

        
    
          
    
            
    

    const faceMesh = ml5.faceMesh(options, modelLoaded);

function modelLoaded() {
  console.log("Model loaded");
}
    
            
    
          
    
        
    
      
    • 
      
  • 
        
    Offline
    
        
    Not every ml5.js model supports pointing at local files, and the option differs per model, so check that model's own reference page (like the FaceMesh and HandPose links below) for a modelUrl or similar setting in its options. Where it's supported, download the model files while you still have internet access, save them next to your sketch, and pass their local path in:
    

        
    
          
    
            
    

    const faceMesh = ml5.faceMesh({ modelUrl: "models/facemesh/model.json" }, modelLoaded);
    
            
    
          
    
        
    

        
    If a model doesn't offer this option, it will always need internet access the first time it loads, even if the ml5.js and p5.js library files themselves are local.

Other models

    
FaceMesh and HandPose are only two of many models ml5.js offers, covering things like body pose, object detection, sound and image classification, and text generation. Browse the full list on the ml5.js examples page.

    
Training your own model, instead of using one of ml5's pretrained ones, is also possible with tools like ml5.neuralNetwork(), or a no-code option like Google's Teachable Machine, which can export a model ml5.js can load directly.
